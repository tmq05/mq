# Thư mục ảnh đại diện có sẵn (Preset Avatars)

Hiện tại các ảnh đại diện có sẵn trong `client/src/data/presetAvatars.ts` đang dùng placeholder từ **DiceBear v9** (`https://api.dicebear.com/9.x/...`) để hiển thị ngay mà không cần tải file nặng.

Khi có bộ ảnh riêng (khuyến nghị định dạng `.webp`, kích thước vuông `256x256`, dung lượng `< 30KB/ảnh`), bạn chỉ cần:
1. Đặt file vào thư mục này theo quy ước tên:
   - `animal-01.webp`, `animal-02.webp`, ...
   - `character-01.webp`, `character-02.webp`, ...
   - `music-01.webp`, `music-02.webp`, ...
   - `abstract-01.webp`, `abstract-02.webp`, ...
   - `nature-01.webp`, `nature-02.webp`, ...
2. Cập nhật trường `url` tương ứng (ví dụ `/avatars/animal-01.webp`) trong:
   - `client/src/data/presetAvatars.ts`
   - `server/src/config/preset-avatars.ts`
